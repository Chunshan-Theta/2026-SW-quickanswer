# Feature Specification: 線上課堂搶答系統

**Feature Branch**: `001-live-classroom-quiz`

**Created**: 2026-11-03

**Status**: Draft

**Input**: User description: 建立僅含核心功能的線上課堂搶答系統，支援教師匯入 Google Sheets Guided Notes、逐題同步搶答、由最快送出答案的組別獲勝，並將得獎答案動態寫回原工作表。

## User Scenarios & Testing *(mandatory)*

### User Story 1 - 匯入並確認 Guided Notes (Priority: P1)

教師選取原始 Google Sheets Guided Notes 工作表，匯入以題號標示的單題簡答題。系統辨識題目和各題對應的空白答案格，確認題數與學習單一致後，教師才能開始活動。

**Why this priority**: 正確的題號與答案格對應是進行搶答及回填的前提。

**Independent Test**: 使用題號、題目和空白答案格可辨識的工作表匯入，確認所有題目可檢視且題數一致；更動題目排列或儲存格位置後重匯，確認配對仍依題號而非固定位置。

**Acceptance Scenarios**:

1. **Given** 教師具有原工作表的讀寫權限且題號唯一、各題答案格可辨識，**When** 教師匯入工作表，**Then** 系統顯示依題號整理的單題簡答題，且題數與學習單一致。
2. **Given** 工作表有缺題、重複題號、無法配對的答案格或題數不一致，**When** 教師嘗試準備活動，**Then** 系統指出問題並阻止活動開始。
3. **Given** 題目或答案格移至工作表中的其他位置，**When** 教師重新匯入，**Then** 系統依題號重新辨識答案格，不以固定儲存格位置配對。

---

### User Story 2 - 進行同步小組搶答 (Priority: P1)

教師逐題開啟或結束搶答；學生以組別加入，並在題目開放時代表該組提交一份簡答。系統同步活動階段，依受理順序判定每題最快送出的組別。

**Why this priority**: 即時且一致的開放、提交與先後判定構成課堂搶答的核心體驗。

**Independent Test**: 讓教師開啟一題、兩個組別先後送出答案，再關閉該題；驗證教師與學生看到相同階段，且第一份受理答案的組別勝出。

**Acceptance Scenarios**:

1. **Given** 題目已完成匯入且尚未開放，**When** 教師開啟該題，**Then** 所有已加入的使用者都看到搶答中狀態，學生可提交答案。
2. **Given** 搶答中且某組尚未提交，**When** 該組送出答案，**Then** 系統確認收到並記錄該組該題的首次送達順序。
3. **Given** 同一題有多組提交，**When** 系統確認各份答案，**Then** 最先受理答案的組別被判定為該題搶答成功組別；同時送達時依系統受理先後順序決定。
4. **Given** 該題已關閉，**When** 學生嘗試提交或更改答案，**Then** 系統拒絕該次提交，且不改變已確認的順序與得獎組別。

---

### User Story 3 - 查看結果並回填原工作表 (Priority: P2)

教師可在搶答期間檢視各組提交狀況與順序；結束後，師生可檢視最終結果。教師可將各題得獎組別的答案動態寫回原 Guided Notes 的答案空格。

**Why this priority**: 結果透明且能回到原學習單，才能完成教師課堂活動與教材整理流程。

**Independent Test**: 在一題中讓多組提交，驗證教師可即時檢視而學生看不到他組資訊；關閉後確認學生可看結果，並驗證得獎答案只寫入原工作表對應題號的空格。

**Acceptance Scenarios**:

1. **Given** 搶答仍開放，**When** 教師檢視活動，**Then** 教師可查看各組的提交狀態、答案及目前順序；學生僅能查看活動階段、自組答案和送達確認。
2. **Given** 搶答已結束，**When** 學生檢視活動，**Then** 學生可查看各組最終作答與每題的得獎組別及順序。
3. **Given** 教師選擇回填已結束題目的結果且仍有原工作表編輯權限，**When** 系統執行回填，**Then** 每題得獎答案依題號寫入原工作表對應空格，其他題目內容不變。
4. **Given** 工作表權限遭撤銷或題號與答案格無法唯一配對，**When** 教師執行回填，**Then** 系統明確回報未完成的題目，不宣稱回填成功，且不把答案寫入無法確認的格子。

### Edge Cases

- 同一時間有多組送出答案時，依系統確認受理的先後順序決定名次；不得因學生裝置時間不同而改變順序。
- 教師結束搶答時有答案正在送達；只有在結束狀態生效前已獲系統確認的答案列入該題結果。
- 教師結束一題時尚無組別作答；該題顯示無得獎組別，且可繼續處理其他題目。
- 題號重複、缺漏、題數不符，或題號與空白答案格無法明確對應；系統不得讓教師開始活動或回填該工作表。
- 學生失去連線或重新加入時；學生不得因此看到尚未結束題目的他組作答狀況，已確認的組別答案與順序不得遺失。
- 教師沒有原工作表讀取或編輯權限時；系統須指出權限問題並停止相應匯入或回填。
- 學生在題目開放前、結束後，或同組已送出後再次提交；系統拒絕提交並保留首次有效答案。

## Requirements *(mandatory)*

### Functional Requirements

- **FR-001**: System MUST 提供教師與學生兩種角色及各自對應的活動操作。
- **FR-002**: 教師 MUST 能選取並匯入其有權存取的 Google Sheets Guided Notes 工作表。
- **FR-003**: System MUST 僅支援以唯一題號表示的單題簡答題；一個活動中的題目數 MUST 與來源學習單題數一致。
- **FR-004**: System MUST 依工作表中的題號及其語意關聯動態辨識題目與答案空格，不得以固定儲存格座標或硬編碼位置作為題目或答案的對應依據。
- **FR-005**: 題目有缺漏、重複題號、題數不符或答案空格無法唯一辨識時，系統 MUST 顯示可處理的錯誤，並禁止開始活動或對未確認的空格回填。
- **FR-006**: 教師 MUST 能依序選取題目並手動開啟及結束該題搶答；同一時間 MUST 只有一題可供搶答。
- **FR-007**: 教師開啟或結束搶答後，系統 MUST 將活動階段同步給所有已加入的使用者。
- **FR-008**: 學生 MUST 能以組別加入活動，並僅能在題目開放期間代表該組提交該題的一份答案。
- **FR-009**: 系統 MUST 以首次獲確認受理的答案判定該組該題的提交順序；教師結束題目後不得再接受該題答案。
- **FR-010**: 系統 MUST 自動將每題最先受理答案的組別判定為該題搶答成功組別；順序相同時 MUST 依系統受理順序決定唯一結果。
- **FR-011**: 教師 MUST 能在搶答期間檢視各組提交狀態、答案及目前順序，並在結束後查看最終結果。
- **FR-012**: 搶答未結束前，學生 MUST 只能查看活動階段、自組提交狀態與自組答案，不得查看其他組別的答案、提交狀況、順序或得獎資訊。
- **FR-013**: 搶答結束後，學生 MUST 能查看各組最終作答、提交順序及該題得獎組別。
- **FR-014**: 教師 MUST 能將每題得獎組別的答案動態寫回原 Guided Notes 工作表中依題號辨識的答案空格。
- **FR-015**: 回填 MUST 保留原工作表中非目標答案格的內容；遇到權限或配對錯誤時，系統 MUST 明確呈現失敗結果，且不得回報未實際完成的回填為成功。
- **FR-016**: 未有任何組別提交的題目 MUST 顯示無得獎組別，不得以其他題目的結果代替。

### Key Entities *(include if feature involves data)*

- **活動**：教師建立並控制的課堂搶答，包含來源學習單、題目清單及目前活動階段。
- **題目**：來源學習單中的單題簡答題，以唯一題號、題目敘述及其答案空格識別。
- **組別**：以單一身分參與同一活動並代表該組提交答案的學生群體。
- **搶答回合**：一個題目從教師開啟至結束的期間，包含階段、各組提交及最終結果。
- **作答提交**：某組對某題首次獲確認受理的答案與其系統順序。
- **學習單對應**：來源工作表、題號與該題答案空格間依內容動態辨識的關係。

## Success Criteria *(mandatory)*

### Measurable Outcomes

- **SC-001**: 對所有符合支援格式且題號唯一的學習單，匯入後辨識的題目數與來源題目數完全一致；題號或答案空格有歧義時，系統在活動開始前指出問題。
- **SC-002**: 教師開啟或結束一題後，至少 95% 仍連線的使用者在 2 秒內看到相同活動階段。
- **SC-003**: 每題的結果均與系統確認受理的答案順序一致，並且只產生一個最先提交的得獎組別；沒有提交時則不產生得獎組別。
- **SC-004**: 搶答開放期間，學生端對他組答案、提交狀況與順序的可見事件為零；題目結束後，學生可檢視最終結果。
- **SC-005**: 回填成功時，所有得獎答案均寫入題號對應的原始空格，且非目標工作表內容保持不變；無法確認對應時，不發生該格寫入。
- **SC-006**: 在可用的課堂網路下，至少 90% 首次使用的教師無需他人協助，即可完成匯入、開啟一題、結束並回填結果。

## Assumptions

- 教師已登入可存取 Google Sheets 的帳戶，並對所選來源工作表具有讀取及回填所需的編輯權限。
- 每次活動使用一個來源工作表；每題有唯一題號及一個可依題號與內容關係辨識的答案空格。工作表欄列位置可變，但題目與空格的關聯資訊必須明確。
- 教師在活動開始前設定可參與的組別；學生透過活動提供的加入方式選擇其組別。帳戶管理、班級名冊及組隊功能不屬於本階段核心範圍。
- 每組每題只接受一份首次提交答案；系統不依答案正誤改變搶答順序，最先送達的答案即為得獎答案。
- 一個活動逐題進行，每題由教師個別開啟及結束；尚未進行的題目不接受作答。
- 學生在題目結束後可查看所有組別的最終答案與順序；題目開放期間不提供即時排名或他組狀態。
- 本階段只處理單題簡答，不包含選擇題、自動評分、多題組或題組子題。
