# Feature Specification: 教師選擇回填答案與學生端正確答案公布

**Feature Branch**: `feat/005-teacher-selected-answer`

**Created**: 2026-11-25

**Status**: Draft

**Input**: User description: 當組別搶答完成後，教師頁面能看到所有組別回答答案和順序，回填答案時要讓教師可以選擇回填的答案，因為即使第一個答的組別也不見得正確。回填完成後，所有組別看到的答案會是 1. 他們自己送出的答案 2. 老師所選的正確答案（包含組別名稱），兩者都要顯示。

## Clarifications

### Session 2026-11-25

- Q: 題目結束後學生要看到哪些答案？ → A: 「只顯示自己＋老師採用的答案」：題目結束後學生只看到自己組別的答案（含自己的送出順位）與「等待老師公布正確答案」；該題回填成功後再加上老師採用的答案與其組別名稱。學生看不到其他組別的答案，也看不到最快組別的名稱。
- Q: 如果沒有任何一組答對，老師可以怎麼處理？ → A: 「也可以自行輸入正確答案」：除了從各組答案中擇一，老師也能自行輸入正確答案回填（題組為每個子題一欄）；學生端顯示「老師提供」，不帶任何組別名稱。
- Q: 回填完成後可以改選嗎？ → A: 可以。回填後老師可改選其他組別或改為自行輸入，並重新回填（覆寫該題作答格，學生端看到的正確答案隨之更新）；以相同選擇再次送出不會重複寫入。
- Q: 預設選取哪個答案？ → A: 尚未回填過時預設選取最快作答的組別；已回填過則預設選取目前採用的答案。

## User Scenarios & Testing *(mandatory)*

### User Story 1 - 教師選擇要回填的答案 (Priority: P1)

題目結束後，教師在該題卡片上看到所有組別依送出順序排列的答案，從中選擇一組（預設為最快的組別）作為正確答案，按「回填所選答案」寫入學習單。回填成功後，若發現選錯，可以改選其他組別並「重新回填」。

**Why this priority**: 使用者明確指出「即使第一個答的組別也不見得正確」，目前回填固定寫入最快組別的答案，會把錯誤答案寫進學習單；這是本功能的核心。

**Independent Test**: 讓 A 組最快送出錯誤答案、B 組第二個送出正確答案；結束題目後選擇 B 組並回填，確認試算表該題作答格寫入 B 組答案；再改選 A 組重新回填，確認作答格改成 A 組答案。

**Acceptance Scenarios**:

1. **Given** 第 1 題已結束，A 組第 1、B 組第 2 送出，**When** 教師檢視第 1 題卡片，**Then** 依順序列出 A、B 兩組答案，預設選取 A 組（最快）。
2. **Given** 教師改選 B 組，**When** 按「回填所選答案」，**Then** 試算表第 1 題作答格寫入 B 組的答案（題組保留「（1）」「（2）」標記），卡片顯示「已回填：B 的答案」。
3. **Given** 第 1 題已回填 B 組答案，**When** 教師改選 A 組並按「重新回填」，**Then** 作答格改為 A 組答案，卡片顯示「已回填：A 的答案」。
4. **Given** 第 1 題已回填 B 組答案，**When** 教師以相同選擇（B 組）再次送出，**Then** 系統不重複寫入，維持「已回填」。
5. **Given** 第 1 題回填仍在處理中，**When** 教師改選其他組別送出，**Then** 系統拒絕並提示等待目前回填完成後再改選；相同選擇再次送出則回到同一筆回填工作。
6. **Given** 第 1 題回填失敗（例如工作表結構被改動），**When** 教師修正工作表後以相同或不同答案重新回填，**Then** 系統重新排入回填。

### User Story 2 - 學生看到自己的答案與老師採用的正確答案 (Priority: P1)

題目結束後，學生在該題卡片上看到「你們的答案」（自己組別送出的答案與順位），以及「正確答案（老師採用）」；在老師回填成功前，正確答案區顯示「等待老師公布正確答案」。學生看不到其他組別的答案，也看不到最快作答的組別。

**Why this priority**: 使用者明確要求回填完成後「兩者都要顯示」；同時題目結束後不再公開所有組別答案，避免學生在老師判定前就以最快組別為正解。與 US1 同為核心。

**Independent Test**: A、B 兩組作答後結束題目，確認兩組學生端都只看到自己組別的答案與「等待老師公布正確答案」；老師選 B 組回填成功後，兩組學生端都出現「正確答案（老師採用）：B」與 B 組答案；重新整理頁面後仍一致。

**Acceptance Scenarios**:

1. **Given** 第 1 題剛結束，**When** A 組學生檢視第 1 題，**Then** 看到「你們的答案」（A 組答案與第 1 個送出）與「等待老師公布正確答案」，看不到 B 組答案或「最快：A」之類的最快組別資訊。
2. **Given** 老師選擇 B 組並回填成功，**When** A、B 兩組學生檢視第 1 題，**Then** 都看到自己組別的答案，以及「正確答案（老師採用）」：B 組名稱與 B 組答案。
3. **Given** 老師改選並重新回填成功，**When** 學生檢視該題，**Then** 正確答案更新為最新一次成功回填的答案。
4. **Given** 某組沒有在第 1 題作答，**When** 該組學生檢視第 1 題，**Then** 顯示「你們沒有在本題作答」，回填成功後同樣看到老師採用的答案。
5. **Given** 回填處理中或失敗，**When** 學生檢視該題，**Then** 維持顯示上一次成功公布的正確答案；從未成功時顯示「等待老師公布正確答案」。
6. **Given** 學生重新整理頁面或斷線重連，**When** 頁面恢復，**Then** 顯示內容與即時更新時一致，仍不含其他組別答案。

### User Story 3 - 教師自行輸入正確答案 (Priority: P2)

若沒有任何組別答對（或沒有組別作答），教師選擇「自行輸入正確答案」，填寫答案（題組每個子題一欄）後回填。學生端看到的正確答案標示為「老師提供」，不帶組別名稱。

**Why this priority**: 使用者已選擇此選項；它補足「各組都答錯」的情況，但核心流程（US1、US2）不依賴它。

**Independent Test**: A、B 兩組都答錯，教師選「自行輸入正確答案」並輸入正解回填；試算表寫入教師輸入的答案，學生端看到「正確答案（老師提供）」。

**Acceptance Scenarios**:

1. **Given** 第 2 題為 2 小題的題組，**When** 教師選「自行輸入正確答案」，**Then** 出現 2 個輸入欄位，分別標示（1）（2）與子題敘述；任一欄空白時不能回填。
2. **Given** 教師輸入完整答案並回填成功，**When** 學生檢視該題，**Then** 看到「正確答案（老師提供）」與教師輸入的答案。
3. **Given** 某題沒有任何組別作答，**When** 教師檢視該題卡片，**Then** 只能自行輸入正確答案回填。

---

### Edge Cases

- 教師選擇的組別不在該題的送出名單中（例如以 API 直接送出），或自行輸入的答案數與子題數不符、含空白：拒絕且不排入回填，教師端提示原因。
- 舊版用戶端只送出 `{ requestId }`：維持既有行為，以最快組別答案回填；若該題無人作答則拒絕。
- 工作表結構在匯入後被改動：維持既有 fail-closed 行為，回填失敗、不寫入；教師可在修正後重新回填。
- 標記版面（`{{answer:N}}`）的學習單在第一次回填後標記已被答案取代：重新回填時，若作答格內容等於上一次成功回填的答案，視為同一作答格並覆寫。
- 多個教師視窗同時操作：以伺服器端最新回填工作為準；處理中時不同選擇被拒絕，避免兩筆回填互相覆寫。
- 答案很長：教師端選項與學生端顯示完整換行，不超出卡片。
- 活動已完成（所有題目都結束）：仍可選擇答案並回填或重新回填。

## Requirements *(mandatory)*

### Functional Requirements

- **FR-001**: 題目結束後，教師端該題卡片 MUST 依送出順序列出所有組別的答案（題組逐子題顯示），並讓教師選擇其中一組作為回填答案；尚未回填時預設選取最快的組別，已回填時預設選取目前採用的答案。
- **FR-002**: 教師 MUST 能改為「自行輸入正確答案」，題組為每個子題一欄；任一欄為空白時 MUST NOT 允許送出。
- **FR-003**: 回填 MUST 寫入教師選擇的答案（題組保留子題標記），MUST NOT 寫入其他答案。
- **FR-004**: 回填成功後，教師 MUST 能改選其他答案並重新回填，新答案覆寫該題作答格；以相同選擇再次送出 MUST NOT 產生新的寫入。
- **FR-005**: 該題回填處理中（排隊、執行中或等待重試）時，以不同選擇送出 MUST 被拒絕並提示稍後再試；以相同選擇送出 MUST 回傳同一筆回填工作。
- **FR-006**: 回填失敗後，教師 MUST 能以相同或不同的選擇重新回填。
- **FR-007**: 選擇的組別不在該題送出名單中，或自行輸入的答案數與子題數不符、含空白、超過長度上限時，系統 MUST 拒絕且 MUST NOT 排入回填。
- **FR-008**: 該題沒有任何組別作答時，教師 MUST 仍能以自行輸入的答案回填。
- **FR-009**: 題目結束後，學生 MUST 只收到自己組別的答案與送出順位；MUST NOT 收到其他組別的答案、順位或最快組別名稱。此規則 MUST 一致適用於即時事件、頁面重新整理（snapshot）與結果查詢 API。
- **FR-010**: 該題回填成功後，所有學生 MUST 看到老師採用的正確答案：來源為組別時顯示組別名稱與答案，自行輸入時顯示「老師提供」與答案；尚未成功前 MUST 顯示「等待老師公布正確答案」。
- **FR-011**: 重新回填成功後，學生端的正確答案 MUST 更新為最新一次成功回填的答案；回填處理中或失敗時 MUST 維持上一次成功公布的答案。
- **FR-012**: 教師端 MUST 顯示每題的回填狀態與採用答案的來源（例如「已回填：B 的答案」「已回填：老師提供」「回填中」「回填失敗」）。
- **FR-013**: 未指定選擇的舊版回填請求 MUST 以最快組別的答案回填（與 001–004 相容）。
- **FR-014**: 教師端選擇介面 MUST 可用鍵盤操作並有可存取的標籤；長答案 MUST 完整換行，360px 寬度可用。

### Key Entities

- **採用選擇（Adoption Selection）**: 教師對某題的回填選擇，來源為「組別」（指定組別）或「老師提供」（每子題一個答案）。
- **回填工作（Writeback Job）**: 每題一筆，記錄目前採用的來源、組別、答案、修訂次數與狀態；改選時以新修訂重新排入。
- **公布答案（Published Answer）**: 某題最近一次成功回填的答案，包含來源、組別（老師提供時無）、答案與公布時間；學生端只會看到這個答案與自己組別的答案。

## Success Criteria *(mandatory)*

### Measurable Outcomes

- **SC-001**: 教師可在 2 次操作內（選擇答案、按回填）把非最快組別的答案回填到學習單。
- **SC-002**: 自動化隱私測試中，學生端從即時事件、snapshot 與結果 API 取得的資料 0 次包含其他組別的答案或最快組別名稱。
- **SC-003**: 回填成功後，已連線的學生在 2 秒內看到老師採用的正確答案（沿用既有即時同步）。
- **SC-004**: 重新回填後，學習單該題作答格只保留最新一次採用的答案（人工驗證）。
- **SC-005**: 以相同選擇重複送出回填 0 次產生額外的工作表寫入。

## Assumptions

- 「正確答案」以教師的選擇為準，系統不自動判斷答案正確與否。
- 回填仍為每題一筆工作，由既有的回填 worker 執行；不改變工作表的寫入格式。
- 教師端仍可看到所有組別的答案與順位；隱私限制只適用學生端。
- 學生端的「已公布結果」改為每題顯示自己組別答案與老師採用的答案，不再列出所有組別。
